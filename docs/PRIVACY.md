# Lumeth Privacy Policy

Effective date: 2026-11-10

Lumeth reads system counters and sensor events only on the device where it is
running. It does not collect, transmit, sell, or share personal data.

The app does not make network requests, does not include analytics or
advertising SDKs, and does not install a background daemon or privileged
helper. Settings are stored locally in macOS UserDefaults.

Temperature readings use the root-free IOHID event path. Fan speed and fan
control are not implemented.

If you have questions about this policy, open an issue in the project's GitHub
repository.

---

# Lumeth 隐私政策

生效日期：2026-11-10

流衡只在当前设备读取系统计数器与传感器事件，不收集、不上传、不出售、不共享个人数据。

应用不发起网络请求，不包含分析或广告 SDK，也不安装后台守护进程或特权助手。设置仅保存在本机 macOS UserDefaults 中。

温度通过无需 root 的 IOHID 事件路径读取；当前版本不实现风扇转速与风扇控制。

如对隐私政策有疑问，可在项目的 GitHub 仓库提交 issue。
